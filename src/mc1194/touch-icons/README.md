# touch-icons — real Bedrock touch-control art (Mojang assets, fair-use UI homage)

24 tiny PNGs copied from a vanilla Bedrock resource-pack mirror
(ZtechNetwork/MCBVanillaResourcePack on GitHub):
- textures/gui/controls/: up/down/left/right (+_pressed), jump_dpad (+_pressed),
  sneak_dpad (+_pressed), flyingascend/flyingdescend (+_pressed), dismount (+_pressed)
- textures/ui/: pause_icon, comment (chat), elipses (inventory "..."),
  arrow_down (drop), keyboard_and_mouse_glyph (keyboard), chat_send (send)

Rebuild: fetch the same paths from
https://raw.githubusercontent.com/ZtechNetwork/MCBVanillaResourcePack/HEAD/<path>
(drawn in-canvas by src/mc1194/touch-controls.js).
